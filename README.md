# 每日科技深挖

这是一份公开的每日笔记：每天从互联网与科技行业里挑**一条**新闻，顺着来源往下挖，写成一篇短文。目标不是资讯汇总，而是把一条新闻放回它的背景里，看清它为什么重要、会影响谁、接下来还该盯什么。

## 这是谁的记录

这是个人公开日志，用来留下当天真正读过、想过的那一条。欢迎阅读；不接受代写选题或未经讨论的大幅改写。

## 条目怎么组织

每天一篇，放在 `digests/` 下，文件名用当天日期：

```text
digests/YYYY-MM-DD.md
```

例如 `digests/2026-11-09.md`。一天只对应一个文件、一条新闻。新条目按 [`digests/_TEMPLATE.md`](digests/_TEMPLATE.md) 起稿，写完后删掉模板里的提示语。

`digests/` 目前只有模板和占位文件，还没有首篇日期笔记。

## 写法

- 用中文散文写，读起来像笔记，而不是要点清单堆砌。
- 一条新闻配一篇。背景可以引用相关报道，但正文始终围绕当天这一条。
- 来源要带链接。关键事实标注出处，方便以后回看。
- 深挖至少覆盖四块：背景、为什么重要、影响、待观察点。最后写自己的看法，并和事实分开。
- 不编造引语、数字或未读过的报道。拿不准就写明不确定。

自动化每天新增一篇 `digests/YYYY-MM-DD.md` 即可，不必再改本说明，除非目录约定本身变了。
