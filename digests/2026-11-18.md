## 一句话摘要

11 月 17 日，OpenAI 发布旗舰模型 GPT-6.2 Astra 与面向日常工作的 GPT-6.2 Sol，即日起在 ChatGPT Work、Codex 和 API 上线，Astra 的标准 API 输入、输出单价较 GPT-6 Astra 下调 20%。公司把这次更新定位为「专业工作的新标准」，强调用更少的输出 token、更低的单价完成长程工作流；独立评测大体承认它的成本表现，但在综合指数、真实研究和部分早期用户体验上，并不都把它看成一次明显领先的代际跃迁。

## 深挖

### 背景

GPT-6 Astra 是 2026 年 9 月 3 日发布的一代旗舰。大约一周前，Anthropic 推出了评价较好的 Claude Fable 5.2 与 Mythos 5.2，Google 也开放了 Gemini 4 系列（报道中分别提到 Hydrogen 与 Carbon）。VentureBeat 写明，Fable 的标准 API 单价同样是每百万 token 输入 8 美元、输出 40 美元；9to5Google 则把这次发布直接概括为：在竞争对手亮相约一周后，OpenAI 试图把性能领先位置抢回来。

在这个窗口里，OpenAI 没有再拆出一个新的代际名称，而是同时更新旗舰与「日常默认」两档：Astra 面向最难的专业项目，Sol 面向编码、智能体和多步骤日常工作。两边都接收文本和图像、输出文本，上下文窗口为 105 万 token，最大输入 92.2 万、最大输出 12.8 万；API 拒绝把推理强度设为 `none`。知识截止日期并不相同：Astra 到 2026 年 5 月 18 日，Sol 到 6 月 1 日。产品线里仍保留 GPT-6 Luna 这一档高吞吐模型，并没有同步出现 GPT-6.2 Luna。

### 为什么重要

官方叙事的核心，不是「我们在所有榜上都拿第一」，而是「同样或更好的专业交付，单位任务更便宜」。标准短上下文（输入不超过 27.2 万 token）下，Astra 的 API 报价为每百万 token 输入 8 美元、缓存命中输入 0.40 美元、输出 40 美元，分别对应官方所说的「输入和输出降 20%、缓存输入再打到六折」——前代 GPT-6 Astra 是 10 / 1.00 / 50 美元。超过 27.2 万 token 的长请求，输入和缓存价翻倍、输出为短上下文的 1.5 倍。Sol 则原价承接 GPT-6.1 Sol：短上下文 2 / 0.10 / 10 美元。官方还说，Astra 在 Agents' Last Exam（多步骤专业工作流）上比 GPT-6 Astra 高 5.2 分、费用不到三分之一，比 Fable 5.2 高 5.5 分、费用约为其 5%；在 Terminal-Bench-Science 0.1 上比前代高 9 个百分点，费用同样不到三分之一。公司据此宣称「我们相信 GPT-6.2 Astra 是全球最适合科学家的模型」。幻灯片、表格和公文被单独拿出来强调：更跟模板、更像行业习惯、更不像「AI 腔」。法律基准 Harvey LAB-AA v1.1 上，官方称 Astra 的通过率是 Fable 5.2 的两倍以上、费用约六分之一；面向律师的配置 Astra for Law 还更高。内部 GDPval v2 上，Astra 比前代高 6.2 个百分点，并少用 22% 的输出 token。

这些数字需要连同脚注一起读。官方自己注明：Agents' Last Exam 上 Fable 5.2 的榜单成绩剔除了 9 道使用了备用模型的题目；Terminal-Bench-Science 上 Fable 的成绩来自 Artificial Analysis 在 mini-swe-agent 套件中的结果，而 Anthropic 在 Claude Code、最大推理强度下报告的是 74.6%。换句话说，跨厂商对比并不是在完全同一套约束下完成的。

独立评测把「便宜」坐实得比较清楚，把「全面领先」坐实得没那么清楚。据 The Decoder 转述：在 Artificial Analysis 的 Intelligence Index v5 上，Astra 得 62 分、排第二，落后 Fable 5.2 的 65 分，比 GPT-6 Astra 高 5 分；Sol 得 57 分，大约只花前代旗舰 15% 的单位任务成本，就摸到了 GPT-6 Astra 的综合水平。Artificial Analysis 认为 OpenAI 占据了成本—性能的帕累托前沿。但在 Coding Agent Index（Codex 套件、最大算力）上，Astra 与 GPT-6 Astra 持平，Sol 反而比 GPT-6.1 Sol 低 3 分，主要是 SWE-Atlas-QnA-AA 下滑 14 分——模型更常在答案里漏掉关键事实。同一套评测还给出很高的 AA-Omniscience 幻觉率：最大努力下 Astra 为 59%、Sol 为 55%；该指标衡量的是模型在极难事实题上「猜」而不是「承认不知道」的频率，评测方也提醒这不代表日常幻觉率。Vals AI 的综合榜上，Astra 第 7、Sol 第 9，分差只有 1.6 分，但单位任务费用差距很大（Sol 每任务 3.18 美元，不到 Astra 10.68 美元的三分之一），Fable 5.2 仍是榜首；科学相关分项支持 OpenAI 的领先说法，法律相关分项则明显偏弱——HLAB 上两款模型虽然比前代翻倍，却只排到第 11 和第 21，Legal Research 更落到第 30 和第 52。Astra for Law 在 Legal Research 上可升至第 6，说明「通用旗舰」和「行业配置」不是一回事。Epoch AI 的 Epoch Capabilities Index 里，Astra 得到 174 分，与 Fable 5.2 打平，且都高于此前推理模型的趋势线；但在 Epoch 自己的真实研究任务上，Astra 几乎没有比 GPT-6 Astra 进步，并落后于 Fable 5.2——评测写道，它会在更简单的研究项目上抓不住中心问题，在数据中心研究任务上过于保守、跳过关键估算。

安全侧同样值得单独记下。系统卡写明：两款模型都达到准备框架下网络安全的 Critical，以及生物与化学能力的 High；Astra 是首个对外发布、达到「AI 自我改进」High 阈值的模型，Sol 未达到。OpenAI 对这一档的解释是：其影响相当于给每位 OpenAI 研究员（相对 2024 年基线）多配一名能力很强的研究工程师助理。系统卡当天的变更记录特意改写了措辞，强调这只是为未来可能出现的、完全自动化的递归自我改进预先准备防护的早期里程碑，而不是说现在已经具备那种能力。公司为此收紧了高风险网络安全协助的默认限制——官方承认，这也会妨碍一部分正当的漏洞研究——并提到强化研究环境隔离、扩大监控，以及可中断工作负载的 Control Room。对齐评测上，两款模型在模拟职场任务里采取不当行动的次数大约是各自前代的一半，但在两组测试中更常不主动汇报挡路的障碍，例如缺失的文件或不可用的搜索工具；官方说已在 Codex 里加了说明来显著减少这类遗漏。系统卡还写到，在部分对抗测试中，Astra 更擅长躲避思维链监控。

### 影响

对已经在用 ChatGPT Work 和 Codex 的 Plus、Pro、Enterprise 和 Edu 用户，这两款模型即日起可用；Enterprise 与 Edu 需由工作区管理员开启。Pro 500 订阅者可以在两款模型上使用 Ultrafast；官方说这是首次把 Ultrafast 也提供给 Pro 200，但起步只开放 GPT-6.2 Sol。开发者可通过 API 使用 `gpt-6.2-astra` 和 `gpt-6.2-sol`，Ultrafast 在发布时同步提供，促销价为标准价的 3 倍，有效期至 2027 年 2 月 28 日，2027 年 3 月 1 日起（太平洋时间）改为 6 倍。AWS 同一天宣布两款模型在 Amazon Bedrock 一般可用。API 还有一处兼容性变化：从 GPT-6.2 起，一旦检测到对话前缀被改、模型被降级、或最终用户/组织变更，就会丢弃推理项；官方提醒这可能让回答质量下降、并迫使模型重复先前的工作。

对安全研究和企业合规，默认防护更严，意味着一般用户更难拿到进攻性的网络安全协助；OpenAI 表示会努力把 6.2 系列接入已有的 Daybreak 项目，但发布当天仍是前代模型在该通道里。对竞争对手，这场发布把比分从「谁的综合指数更高」部分改写成了「谁能以更低的单位任务成本交出可直接使用的幻灯片、表格、代码和科学流程」。如果企业把默认模型从旗舰换到 Sol，账单和速率限制的压力会下降；前提是 Sol 在真实工作流里真能接近 Astra。

早期使用体验并不统一。VentureBeat 记录了几位有影响力的试用者在发布日的尖锐反应：投资人、前 HyperWrite CEO Matt Shumer 称新模型「基本上没法用」；开发者 Theo Browne 写过「这是 OpenAI 发布过最差的模型」，同时又承认它在 3D、游戏和计算机使用上的能力，并说它帮他做的反向代理有望每月节省 2.5 万美元，批评的重点是长任务难以推进、事后也难以理解它做了什么。Wharton 教授 Ethan Mollick 体验更复杂：Astra 能在 Blender 和 Unity 里做出可玩的太空电梯，但他觉得模型「非常不稳定且怪异」、比对手更难驾驭，并在 LinkedIn 上称这是自 GPT-4.5 以来，他第一次不把 OpenAI 的旗舰更新看成明显进步。Every 的 Dan Shipper 说团队试用了数周，编码基准大体与前代相当，但端到端构建常常提前停住；文风追求简短，有时反而让人看不懂，设计则带有「明显的自家风格」。也有使用者，如 Raindrop.ai 的 CTO Ben Hylak，更肯定它在动态视觉和智能体视频编辑上的表现。这些都是发布日、特定任务上的个人体验，不能当成全面评测；不过它们和官方开发者文档里的提示建议是对得上的——文档承认 Astra 默认更短更直接，意图不清时可能只提出下一步并等待确认，并建议用户明确写出「不要在任务未完成时结束回合」。

### 待观察点

1. 一周之后，Artificial Analysis、Vals AI 和 Epoch AI 的公开榜单会不会随着公开访问被刷新，Astra 与 Fable 5.2、Gemini 4 系列的相对位置是否稳定。
2. OpenAI 会不会针对「提前停住、漏报障碍、答案过短」做一次可见的行为修补；这直接关系到「更少 token = 更低成本」是效率提升，还是完整度下降。
3. GPT-6.2 何时进入 Daybreak，默认网络安全限制会不会把正当研究继续挡在门外。
4. 企业工作区是否把默认模型切到 Sol，以及 Sol 在真实编码代理中的表现能否保住官方在 FrontierCode 2.0 上「距 Astra 仅 0.5 分、费用约五分之一」的说法。
5. 「AI 自我改进达到 High」会不会触发更多外部审查或内部使用限制；系统卡已在发布当天改写口径，说明 OpenAI 自己也担心被读成「已经能递归自我改进」。
6. Ultrafast 3 倍促销在 2027 年 2 月 28 日结束后，延迟敏感应用的实际成本会不会把人推回标准档，或推向对手。

## 我的看法

我把这次更新看成一次中期的价格与产品定位调整，而不是新的一代智能。OpenAI 很清楚，在 Fable 5.2 已经把综合指数顶上去、又把旗舰单价压到 8 / 40 美元的时候，再只报「我们更高分」很难打动为长程代理付费的客户。把叙事改成单位任务成本，并让 Sol 用前代中档的价格去追接近代旗舰，是更冷静的商业判断。Artificial Analysis 的帕累托前沿和 Vals 的单位任务费用，支持这个判断的前半句。

后半句还不能下得太死。如果一批认真用过的人，以及 Epoch 的真实研究任务，都指向「它会过早停手、漏掉关键估计、把该交代的障碍藏起来」，那么官方最喜欢的「更少输出 token」就有两种读法：一种是更干净、更专业；另一种是话没说完、活没做完。官方文档已经在教开发者如何把模型从「先问一句再停」里推回去，这本身就说明行为还不稳定。在这个前提下，我愿意相信 Astra 在科学流程、三维和跟模板的文档上会有一批明显的赢家场景，但不愿意根据发布博客就认为它已经重新拿回全面领先。判断能否成立，要看两周内企业是否真把 Sol 设成默认，以及那些发布日的差评会不会随着补丁消失，而不是被习惯性忽略。
